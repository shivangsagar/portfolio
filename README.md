## About

Welcome to my personal portfolio.

I am an undergraduate Civil Engineering student at Motihari College of Engineering, interested in structural engineering, architectural design, Building Information Modelling (BIM), surveying and technology.

This website serves as a central place to explore my academic background, technical projects, practical experience, certifications and other professional activities.

The portfolio is designed with a minimal dark interface, featuring a green accent colour and a technical drawing-inspired visual style.

## Features

- **Responsive Design:** Optimised for desktop, tablet and mobile screens.
- **Dark Theme:** Minimal black interface with green, white and grey accents.
- **Project Showcase:** Dedicated categories for AutoCAD, Revit, STAAD.Pro and GitHub projects.
- **Playing-Card Project Visuals:** Engineering project cards use a playing-card-inspired visual system.
- **Project Filtering:** Browse projects by category.
- **Show More / Show Less:** Displays three projects initially to keep the interface organised.
- **AutoCAD Drawing Preview:** Preview supported DWG/DXF drawings through MLightCAD.
- **Project Downloads:** Download publicly available project files.
- **HTML Résumé:** View my résumé directly on the website in a format based on the original résumé.
- **PDF Download:** Download the original résumé as a PDF.
- **Certificates & Achievements:** Dedicated section for academic and professional credentials.
- **Experience Section:** Showcases internships, workshops and extracurricular activities.
- **Contact Form:** Send messages directly through Web3Forms with hCaptcha spam protection.
